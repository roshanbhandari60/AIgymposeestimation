
# AI Gym Pose Estimation

A fitness application designed to help users analyze exercise posture and improve workout form.

## Overview

This project aims to support users in performing exercises with better posture by providing a software-based approach to exercise form analysis.

## Repository Structure

- `backend/` - Backend application code.
- `frontendAndroid/` - Android frontend application code.

## Features

- Exercise posture analysis.
- Support for fitness and workout form assessment.
- Backend and Android frontend components.
